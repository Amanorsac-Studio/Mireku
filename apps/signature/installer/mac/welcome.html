MIREKU

Version 1.0.1 · Amanorsac Studio

A sampled keyboard instrument: four voices, an effects rack and a performance stage.

No licence key and no account are required.

The sample library is delivered separately. Set its folder under Settings when MIREKU first opens.

The next pages show the licence, then every part you can install and exactly where each one goes. macOS asks for your password once, because plug-ins are installed for every user of this Mac.
