MIREKU | APPROVED PORTRAIT ICON

Design: engraved ivory portrait on black with gold MIREKU lettering.

CONTENTS
MIREKU-Master-1254.png: original 1254 x 1254 raster artwork, unchanged.
PNG/: lossless exports at 1024, 512, 256, 128, 64, 48, 32 and 16 pixels.
MIREKU.ico: Windows multi-resolution icon, 16, 24, 32, 48, 64, 128 and 256 pixels.
MIREKU.icns: macOS icon container, representations up to 1024 pixels.

IMPLEMENTATION
Use PNG for plugin UI branding and the native containers for standalone applications and installers as appropriate. DAW plugin-list icon support depends on the host. Keep the black background opaque. Artwork is raster, no editable vector/SVG is supplied. Do not redraw the face or stretch the artwork.

Small sizes necessarily lose engraved detail and full-name readability. Inspect in the target operating system and DAW before release; the large master is the visual reference. Files were decoded and their embedded sizes verified; application integration has not been tested.
